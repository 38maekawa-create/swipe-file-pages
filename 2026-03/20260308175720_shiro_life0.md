①どんなドメイン知識を持たせるか
②どんなディレクトリ構造にするか
③どんなナレッジファイルを食わせるか

例えばYouTube台本を自動生成するなら

scripts/
├ gem-tutorial/
│ ├ research/
│ │ ├ x-posts-2026-03.md
│ │ ├ yt-summary.md
│ │ └ competitor-analysis.md
│ ├ draft.md
│ └ final.md
├ knowledge/
│ ├ tone-rules.md
│ ├ script-structure.md
│ ├ ng-expressions.md
│ └ power-phrases.md
└ workflow.md
