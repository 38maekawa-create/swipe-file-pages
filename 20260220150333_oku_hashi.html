    ◆Mac編

    事前に必要なもの

    ・MacmacOS 10.15（Catalina）以降 ・メモリ4GB以上 ・インターネット接続必須 ・AnthropicアカウントClaude Pro/Max プラン、またはAPIキー

    ステップ 1　ターミナルを開く

    ターミナルはMacに最初から入っているアプリです。

  • Spotlight検索を開く → Command ⌘ + Space を同時押し
  • ターミナルと入力して Enter
  • 黒い（または白い）ウィンドウが開けばOK！

    • ターミナルは「Macにテキストで指示を出すためのアプリ」です。 怖がらなくて大丈夫です！

    ステップ 2 Claude Codeをインストールする

    2つの方法があります。お好きな方を選んでください。

    方法1：ワンライナーでインストール（おすすめ・最も簡単）

    ターミナルに以下をコピー＆ペーストして Enter を押します!

    bash

    curl -fsSL https://claude.ai/install.sh | bash

    これだけで自動的にダウンロード＆インストールされます。 Node.jsは不要です。

    方法2 Homebrewでインストール

    すでにHomebrewを使っている方はこちらでもOKです！

    bash

    brew install --cask claude-c Homebrew版は自動アップデートされないため、定期的に brew upgrade claude-code を実行してください。

    ステップ 3　インストールを確認する

    ターミナルで以下を入力して Enter

    bash

    claude --version

    バージョン番号（例：2.1.41）が表示されれば、インストール成功です ！！

    もしエラーが出た場合は、ターミナルを一度閉じて開き直してから再度試してください。

    ステップ 4　認証（ログイン）する

  • ターミナルで以下を入力して Enter

    • bash

    claude

  • 初回起動時、ブラウザが自動的に開きますもし自動で開かない場合は、ターミナルに表示されるURLを Command ⌘ + クリック で開いてください
  • ブラウザでClaudeのアカウントにログインします
  • 認証が完了するとターミナルに戻り、使えるようになります

    • 認証方法の選択肢

    方法対象者Claude Pro / Max プラン月額サブスクリプションで利用したい方（おすすめ）Claude Console（APIキー）従量課金で利用したい方

    実際にプロジェクトフォルダに移動して使ってみましょう：

    cd ~/Desktop/my-project claude

    ここからは実際に僕が作ったツールの 制作手順を公開していきます！

    最初に、ClaudeCodeを起動してターミナルの入力欄にこのように指示しました！ 「> インスタのリール動画用の素材画像を、台本に添った内容で一括で生成できるツールを作りたい。」

    すると、AIが次々とどういう内容で作っていくかを聞いてきてくれるので、

    作りたいイメージに添った回答をしていきます！

    今回はGeminiの画像生成機能をつかって、リール動画の背景用画像を生成してくれるツールを作ってみたいと思います！

    AIが考えてくれた質問に簡単に答えたり、軽く自分のイメージをつたえるだけで、開始数分ですぐにこのようなツールができました！ 途中何回かエラーがでました、AIが勝手に修正してくれます笑

    ツールの背景や、ロゴ、デザインなども作りたいイメージに添って、ClaudeCodeにチャットで伝えてあげれば自由自在に作ってくれます！ 完成したツールを実際に使ってみます！ 用意したリール動画の台本をコピペしてAIで解析をポチっ！

    台本を自動でカット割りして、画像生成用のプロンプトをカットごとに出力してくれました！

    そして画像を一括生成！

    そして出力されたのが....

    おおおおお！！今回は投資に関する台本だったので、シーンに添った内容の画像を一括で生成してくれました！！！ ３０カットとかの素材をいちいち生成していくのは大変なので、 これなら一瞬で素材画像が揃えられますね！！

    気に入らない画像は、カットごとに再生成できるように、チャットで指示して 作ってもらいました！

    このようにチャットの指示だけで、自分が使いやすいように何でも作ってくれます！！ ※一度に大量の指示を出すとうまく処理されない場合が多いので、少しずつ指示を出しながら作っていくのがバイブコーディングのコツです！

    難しいプログラミングも一切不要です笑 ClaudeCodeを使えば、いままで月額を払っていた色んなツールや、 欲しかったツールを自分で作れてしまうんです！！ 例えば、本来外注すると数十万円かかる ホームページやLPが作れたり、 ファイルの整理や、スライド、資料制作や アプリづくり、Webデザインまで全てできてしまいます！ 「ドラえもん」に例えると… ChatGPTやGeminiなどは、 知識豊富な「本」みたいなもんですが、 Claude Codeは実際に手足を動かして部屋の掃除や片付けをしてくれる 「ロボット」です！！ あなたの家にドラえもんがやってきたようなものです！！
